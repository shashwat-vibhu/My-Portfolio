# Shaswat Vibhu — Portfolio

A personal student portfolio website introducing **Shaswat Vibhu**, a B.Tech Computer Science student specializing in **Artificial Intelligence & Machine Learning** at **Bosscoder School of Technology**.

The portfolio brings together an introduction, technical skills, selected projects, interests, and current learning goals in one responsive website.

## ✨ Sections

- **About Me** — A short introduction and education details.
- **Technical Skills** — Programming languages, web technologies, tools, and current learning areas.
- **Selected Projects** — SkillSwap, BISSetu, and Cortex Code.
- **Hobbies & Interests** — Topics and activities beyond coding.
- **Current Learning Goals** — Skills and areas currently being explored.

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript

No framework or build tools are required.

## 📁 Project Structure

```text
My-Portfolio/
├── index.html    # Website structure and content
├── style.css     # Layout, styling, and responsive design
├── script.js     # Mobile navigation interaction
└── README.md     # Project documentation
```

## 🚀 Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/shashwat-vibhu/My-Portfolio.git
   ```

2. Open the project folder:

   ```bash
   cd My-Portfolio
   ```

3. Open `index.html` in your browser, or open the folder in VS Code and use the Live Server extension.

## 🎨 Customize

- Update personal information and project descriptions in `index.html`.
- Change colors, spacing, typography, and responsive layouts in `style.css`.
- Update the navigation behavior in `script.js`.

## 🌐 Deploy with GitHub Pages

1. Open the repository's **Settings** on GitHub.
2. Select **Pages** from the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/ (root)` folder, then save.
5. Once deployment finishes, GitHub Pages will show the published website URL in the Pages settings.
